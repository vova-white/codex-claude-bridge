# Recover unfinished work from recorded process identities, and resume queued work only within the same boot

When the bridge service dies, the Claude Code processes it spawned may outlive it, but no one can observe or control them any more: their stdio belonged to the dead service. A running status in the database proves nothing either way. The service therefore records each Claude Code process it spawns, for executions and nested writers, as its PID together with the boot identifier and the process start time from Linux `/proc`, before the process receives anything. At startup, a process whose PID and start time both still match is provably the one the bridge spawned: the new service stops it (`SIGTERM`, then `SIGKILL`, checking the identity again before each signal so a reused PID is never hit) and reports `stopped`; otherwise it reports `ended`. Where the platform reports no start time, the bridge cannot prove anything and reports `unknown` without signalling. The execution becomes `interrupted` and is never rerun on the bridge's initiative; continuing it is an explicit follow-up that resumes the Claude session and tells Claude it was interrupted, because an edit, push, or pull request it started may or may not have taken effect.

Queued executions never reached Claude Code, so the new service keeps them queued and starts them. That is safe only while the database holds every commit of the previous service. ADR 0004's `synchronous = NORMAL` can lose the latest commits in an OS crash, and a lost commit could hide that a queued execution had already started. The service records the boot identifier in the database at each start, in the same transaction that settles the queued executions, and trusts queued state only when it matches the current boot, so a service that dies during recovery leaves the queue as uncertain as it found it; after a machine restart, or where no boot identifier exists, queued executions are interrupted with `process: unknown` instead. A clean reboot is treated like a crash because the two cannot be told apart.
