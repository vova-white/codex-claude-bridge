# Triage labels

Map each canonical triage role to the label used in this repository.

| Canonical role    | Tracker label     | Meaning                                                 |
| ----------------- | ----------------- | ------------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue                  |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information            |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation                           |
| `wontfix`         | `wontfix`         | Will not be actioned                                    |

When a skill mentions a triage role, use its tracker label from this table.
Edit the tracker label column to adopt a different vocabulary.
